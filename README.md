# CVSs-Health-Finacial-Modeling-Portfolio
This repository contains financial modeling projects analyzing CVS Health historical financial performance, projected results, and estimated intrinsic value.

Project 1: Five-Year Financial Forecast

File: Five Year Forecast Final.xlsx

A integrated 3-statement financial model and 5-year forecast for CVS Health, built using 3 years of historical data (2023–2025) to project the Income Statement, Balance Sheet, and Cash Flow Statement.

Model includes:
- Historical financial statement analysis
- Five-year financial projections
- Projected income statement
- Projected balance sheet
- Projected cash flow statement
- Integration of the three financial statements

Project 2: Discounted Cash Flow(DCF) Valuation

File: CVS's DCF Final.xlsx

A discounted cash flow valuation model built using the five-year financial projected free cash flow and the weighted average cost of capital (WACC) to estimate CVS Health's intrinsic enterprise value.

Model includes:
- Integration with fiver-year financial forcast
- Projected free cash flow
- Weighted average cost of capital (WACC)
- Discounting of projected cash flow
- Enterprise value estimation
- Intrinsic valuation analysis
